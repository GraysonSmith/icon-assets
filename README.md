# icon-assets

一个用于集中存放各种项目中可能会用到的 Icon 的素材仓库，方便统一管理、复用和通过 GitHub 链接直接引用。

## 目录

```text
icon-assets/
└── mihomo/    # Mihomo 配置及相关场景使用的图标
```

后续可按项目、应用或使用场景继续新增目录。

## 使用方式

可以下载仓库中的图标到本地使用，也可以通过 GitHub Raw 链接直接引用：

```text
https://raw.githubusercontent.com/GraysonSmith/icon-assets/main/<目录>/<文件名>
```

例如：

```text
https://raw.githubusercontent.com/GraysonSmith/icon-assets/main/mihomo/Github.png
```

## 添加图标

添加新图标时，建议：

- 按项目或用途分类存放，避免所有文件堆在根目录。
- 使用清晰、稳定的英文文件名，便于通过 URL 引用。
- 优先使用带透明背景的 PNG 或 SVG 格式。
- 替换已有文件前确认其是否已被其他项目引用。
